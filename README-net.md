# brother_ql_web_net

This is derived from https://github.com/FriedrichFroebel/brother_ql_web.

The primary goal was to change from a configuration file to SNMP discovery of Brother QL printers on the network. 

- selection of printers available
- auto selection of the label size from the printer

Secondary goals were to to extend some of the functionality:

- portrait and landscape printing
- improve font and styling selection
- vertical alignment
- cut after each or last label
- allow creation and queuing of second label while first is printing
- optional YYYY-MM-DD timestamp in the label
